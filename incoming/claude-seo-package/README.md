# Claude SEO package upload folder

Эта папка предназначена для материалов SEO-пакета от Клода по КИБЕР ПОРТАЛУ.

Можно загружать сюда:

- ключевые запросы по страницам;
- синонимы и long-tail фразы;
- готовые alt-тексты;
- статьи и черновики;
- подборки;
- таблицы/CSV/Markdown/JSON;
- любые заметки по приоритетным страницам.

## Правила

- Не загружать API keys, пароли, токены, cookie, доступы к аналитике/CRM/Telegram.
- Если материал относится к конкретной странице, желательно включить slug/URL в имя файла.
- Если есть несколько версий, лучше сохранять с датой или номером версии.

## Suggested filenames

```text
keywords-by-page.md
long-tail-phrases.md
alt-texts.md
articles-drafts.md
collections-drafts.md
priority-pages.md
```

После загрузки я разберу материалы и начну SEO enrichment pass.
