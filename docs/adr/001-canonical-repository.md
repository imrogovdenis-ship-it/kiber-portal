# ADR-001: канонический репозиторий Кибер Портала

- Статус: принято
- Дата: 2026-08-26
- Linear: KIBER-3 / KP-001

## Контекст

Код и материалы Кибер Портала существовали в нескольких рабочих копиях и экспортных наборах. Параллельная разработка в таких копиях создаёт риск потери изменений, расхождения production-кода и невозможности воспроизвести релиз.

## Решение

`git@github.com:imrogovdenis-ship-it/kiber-portal.git` назначен единственным каноническим репозиторием проекта.

1. Новая работа начинается от актуального `main` этого репозитория.
2. Изменения вносятся в короткоживущей ветке и проходят review перед слиянием.
3. Hermes и другие агенты используют этот remote; они не создают постоянный параллельный `app-v2` или вторичный репозиторий.
4. Tilda остаётся источником legacy-экспорта до отдельно утверждённого переключения, но не является источником истины для нового application-кода.
5. Полезные материалы из legacy-копий переносятся выборочно, с проверкой секретов, лицензий, происхождения media и отдельным commit.

## Последствия

- `main` отражает принятое состояние проекта и служит основой CI, staging и release image.
- Legacy-репозитории и локальные snapshots считаются read-only до их отдельной архивации.
- При конфликте копий изменения не синхронизируются автоматически: владелец переносит нужный diff в канонический репозиторий через review.
- Production-действия, DNS, secrets и Coolify не разрешаются этим ADR и требуют отдельных задач и approvals.

## Проверка соблюдения

Перед началом работы исполнитель проверяет:

```bash
git remote get-url origin
git status --short
```

Ожидаемый origin: `git@github.com:imrogovdenis-ship-it/kiber-portal.git` (или HTTPS-эквивалент того же GitHub-репозитория).
