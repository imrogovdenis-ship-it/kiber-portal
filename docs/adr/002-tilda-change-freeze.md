# ADR-002: заморозка изменений Tilda до DNS cutover

- Статус: принято
- Дата: 2026-08-26
- Linear: KIBER-5 / KP-004
- Действует: немедленно и до завершения DNS cutover по KP-106

## Контекст

Новая платформа собирается в каноническом Git-репозитории, а текущий production пока обслуживает Tilda. Несогласованные правки Tilda после снятия экспорта делают migration baseline устаревшим и могут потеряться при переключении DNS.

## Решение

Ввести полный freeze редакторских, дизайнерских, SEO и интеграционных изменений в Tilda до DNS cutover.

Запрещены без исключения по процедуре ниже:

- создание, удаление, публикация и переименование страниц;
- изменения URL, title, description, H1, canonical, robots и sitemap;
- изменения блоков, форм, webhook-интеграций, аналитики и подключённого кода;
- замена media и файлов;
- изменения домена и redirect-настроек.

Новый контент и исправления готовятся только в canonical repository через branch/PR. Доступ к Tilda не означает разрешение на публикацию.

## Аварийное исключение

До cutover разрешается только исправление подтверждённого production-инцидента. Перед публикацией владелец проекта должен письменно одобрить изменение в Linear и указать:

1. URL и наблюдаемый ущерб;
2. минимальный diff;
3. исполнителя и время окна;
4. способ проверки и rollback.

После публикации исполнитель в тот же рабочий цикл:

1. экспортирует изменённую страницу и sitemap;
2. переносит эквивалентный diff в canonical repository;
3. прикладывает evidence к Linear issue;
4. запускает проверку drift по KP-005.

Если эти шаги невозможно выполнить, изменение не публикуется.

## Завершение freeze

Freeze прекращается только после выполнения KP-106 и успешного post-cutover smoke KP-107. До этого момента устное согласование и сообщения вне Linear не считаются разрешением.
