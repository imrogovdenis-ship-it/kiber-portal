# Доступность

Целевой уровень — WCAG 2.2 AA.

- Все действия доступны с клавиатуры и имеют видимый `focus-visible`.
- Карточка не превращается в одну вложенную full-card ссылку.
- Содержательные изображения требуют alt; placeholder имеет доступное описание.
- Интерактивные области, контраст и порядок фокуса проверяются до перевода блока в `stable`.
- Анимация должна учитывать `prefers-reduced-motion`.
