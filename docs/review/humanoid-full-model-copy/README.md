# Unitree G1 / Agibot X2: редактура названий и текста

## Задача владельца
Полные названия Unitree G1 / Agibot X2 должны преобладать; короткие обозначения допустимы умеренно. Робот/робот-гуманоид/гуманоид/человекоподобный робот и редкие разговорные варианты распределяются по смыслу, без SEO-переспама. Не менять дизайн, изображения, галереи, цены и подтверждённые характеристики.

## Источники
Существующие Wordstat clusters обеих моделей в docs/review/robot-card-remediation/wordstat-24/clusters и исследование humanoids-g1-x2/COMPETITOR_GAPS.md прочитаны перед редактурой. Повторного сбора не было. Новые коммерческие сочетания составлены по установленному модельному интенту и запросу владельца; новые частотности им не приписываются. EDU/Ultra не подменяют базовые модели.

## Редакторский проход
Исходный вариант: в основных blocks было одно полное название на каждой странице; короткие обозначения преобладали. Проблема не решалась заменой каждого G1/X2: это создало бы повтор названия в каждом предложении.

Первый переписанный вариант дополнительно проверен на одинаковые начала абзацев, канцелярское описание программы и искусственное чередование синонимов. Где модель уже понятна, оставлены «робот», местоимения или редкое сокращение. Уточнена грамматика цитаты X2. В цитате G1 технические характеристики отнесены к Unitree G1, а не к маскоту Гоше. «Андроид»/«робот-человек» употреблены единично в сценарии съёмки, без утверждений о человеческом облике или интеллекте; «киборг» не добавлен.

## Итог
Полный текст — COPY.md, именования — naming-audit.json. Счётчик служит проверкой редакторского требования, а не целевой плотностью ключей. SEO title/primary intent остаются модельными; description/secondary terms/seoIntent согласованы с новым текстом. Canonical в seoIntent.entity приведён к существующей /robots/ странице.

Разрешённый runtime scope: metadata/structured FAQ/seoIntent, aiSummary, capabilities, scenarios, goshaCta, faq. Shared service/order/CTA/navigation, Hero/pricing и обе галереи сохранены. Никаких изменений других моделей, статей, API, DNS или live routing. Публикация на основном домене остаётся под запретом владельца.
