# Мобильные варианты сценарного слайдера

Статические изолированные прототипы по запросу владельца. Только header, исходный Hero, четыре утверждённых сценария и footer. Основной сайт и runtime-исходники не меняются.

- A: общая высота фотографий, естественная ширина, следующий слайд виден.
- B: A + подсказка и кликабельные индикаторы.
- C: одинаковая ширина карточек, более низкие фото без обрезки, стрелки.

CSS ограничен body[data-scenario-proposal] и мобильным breakpoint до 639px; desktop сценарий исходный. Страницы noindex, analytics data-production=false.

Источник: сохранённый публичный HTML принятой страницы Джино в baseline.html; исходные стили, фото и скрипты не скопированы и не заменены, используются существующие URL технического домена. Для воспроизведения: установить requirements.txt в отдельный venv, выполнить generate.py. В site/ сохранён deploy artifact. Это сравнение вариантов, не готовое изменение production-компонента.

Проверки на Джино: 320/390/430/1440 ×3; одинаковая видимая высота фото на мобильном, естественные пропорции, видимый следующий слайд, текст без clipping, нет document overflow, реальные эмулированные touch-origin swipes, индикаторы B и стрелки C, нет JS errors. Основной HTML сравнен по SHA256 до/после.

URLs: https://jino-preview.kiber-portal.ru/preview/scenario-mobile/{a,b,c}/
Rollback: удалить только шесть файлов нового /preview/scenario-mobile/; существующие файлы хостинга не заменялись.

Визуальная приёмка владельца ожидается. Merge/production запрещены до нового разрешения.
