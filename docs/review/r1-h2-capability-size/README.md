# R1/H2: только размеры изображений возможностей

Причина: HTML height=466/393 продолжал задавать разную высоту, несмотря на CSS aspect-ratio. У одобренного G1 уже было height:auto. Исправление — только для capability images R1/H2: height:auto и object-position:center; существующие width:100%, aspect-ratio:16/9 и object-fit:cover сохраняются.

Для каждой страницы удаление шести добавленных style-атрибутов полностью восстанавливает прежний HTML. G1 не изменился вообще. Все CSS побайтно идентичны. Изображения, alt, тексты, ссылки, цены, галереи и другие страницы не менялись.

Регрессия scripts/capability-image-geometry-smoke.mjs воспроизводила неодинаковую высоту и смещение заголовков. Проверяет шесть одинаковых рамок 16:9 во всю ширину, object-fit:cover и выравнивание заголовков в строках на 390/768/1440. Проверка декодирования/HTTP 200 не заменяет проверку геометрии.

Для каждой следующей карточки до приёмки запускать этот тест с ROBOT_SLUGS=<slug>; не считать старое отображение корректным только потому, что CSS не менялся. Фотографии Hero/галерей не унифицировать этим правилом.

Только Jino preview. Без merge, DNS или API изменений.
