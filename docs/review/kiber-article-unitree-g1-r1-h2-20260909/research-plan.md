# План исследования статьи №6

## Статус

Остановлено до пользовательского Wordstat/CDP-доступа. Старые цифры из DOCX считаются только неподтверждённым пользовательским источником и не переносятся в новый SEO-паспорт автоматически.

## Порядок после восстановления доступа

1. Собрать Wordstat заново.
2. На основе Wordstat выбрать primary/secondary/long-tail без захвата generic-ключей подборки.
3. Проверить SERP по выбранным запросам и фактически открыть страницы конкурентов.
4. Проверить официальные страницы Unitree и внутренние robot-card sources.
5. Составить content gaps и SEO-паспорт.
6. Только затем переписать блоки и собрать preview.

## Кандидаты запросов для Wordstat

- `Unitree G1`
- `Unitree R1`
- `Unitree H2`
- `робот Unitree G1`
- `робот Unitree R1`
- `робот Unitree H2`
- `сравнение Unitree`
- `Unitree G1 R1 H2`
- `Unitree G1 или R1`
- `Unitree G1 или H2`
- `Unitree R1 или H2`
- `какой робот Unitree выбрать`
- `какого гуманоида Unitree выбрать для мероприятия`
- `Unitree G1 сравнение`
- `Unitree R1 сравнение`
- `Unitree H2 сравнение`
- `аренда Unitree G1`
- `аренда Unitree R1`
- `аренда Unitree H2`

## SERP-группы

- прямое сравнение G1/R1/H2;
- попарные сравнения;
- обзоры каждой модели;
- выбор гуманоида Unitree для мероприятия;
- коммерческие exact-model запросы только как вторичный мост к robot cards.
