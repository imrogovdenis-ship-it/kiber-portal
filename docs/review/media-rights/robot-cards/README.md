# 24 robot media review cards

Review-only package: **24 robot media review cards** with legacy horizontal hero, current generated hero, catalog card/source hero-gallery images, both original gallery blocks, `actualDescription`, `seoAlt`, `caption`, and rights approval slots.

- Source-of-truth meaningful images: `248`
- Total review assets including legacy/current generated heroes: `296`
- Production remains blocked: `productionApprovedAssets = 0`.

## Why earlier visual cards showed too few gallery images

Earlier cards were generated from `media-rights-review-package.json`, which was based on the rebuilt `robots.generated.json` layer: one current square hero plus a short gallery subset. The original live robot pages contain two `t1148` gallery blocks. The full source-of-truth media library already had those extra meaningful images and richer descriptions, but the visual review cards did not render them all. These cards now render both blocks separately.
