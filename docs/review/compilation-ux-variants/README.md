# Шесть UX-концепций подборок — только техническое превью
Разрешение владельца: A минимальные изменения, B средняя переработка, C новая концепция. По одной полной странице каждого типа для робособак и гуманоидов. Production/merge не разрешены.
Источник: frozen HTML действующих www.kiber-portal.ru/roboty-sobaki/ и /roboty-gumanoidy/. Это прототипы для выбора направления, не новая реализация общих Astro-компонентов.
A: сохранён контент, контекстные CTA, названия/ссылки галереи, CTA после каталога.
B: ранний компактный обзор моделей, затем галерея и гид; сохранены подробности и исходный каталог.
C: новый путь Hero → визуальный выбор с фильтром по роли → как заказать → Гоша → FAQ → CTA. Без длинного гида, общей галереи и дополнительного каталога.
Все цены/изображения извлечены из действующих карточек; роли основаны на опубликованном тексте. Действия моделей согласуются, ставки не означают фиксированный итоговый заказ.
Без аналитики, noindex/nofollow. CTA открывает только демонстрационное окно, формы отсутствуют. Внешние карточки моделей ведут на существующий технический домен.
Генерация: PYTHONPATH=<bs4 vendor> python3 docs/review/compilation-ux-variants/generate.py
Публикация: только новые файлы site/ в /preview/compilation-ux/. Откат — удалить только файлы опубликованного манифеста. Основной сайт и прежние preview пути не заменяются.
