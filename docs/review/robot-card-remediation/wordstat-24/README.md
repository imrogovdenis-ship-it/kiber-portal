# Семантика 24 карточек КИБЕР ПОРТАЛ
Источник: [Яндекс Wordstat](https://wordstat.yandex.ru/). 121 проверенный запрос по 24 моделям. Все регионы; ПК, смартфоны, планшеты. Период сохранён у каждого запроса: интерфейс показывал два разных окна, их нельзя усреднять. Частоты — не число клиентов, не прогноз заявок; пересекающиеся запросы не суммируются.
Сохранены исходные таблицы, фактически введённые запросы, скриншоты, CSV, 24 модельных файла кластеров и исключений. Нулевой объём и ненулевой итог без раскрытых строк таблицы различаются.
**Wordstat закрыт для согласованного плана. Это не обещание исчерпать любые будущие запросы и не завершённый SERP/фактчек всех 24 моделей.** FAQ-темы отмечены как редакционные вопросы заказчика, а не выдуманные измеренные запросы.
## Решения
- Карточки сохраняют точную модель/услугу. Общие классы и сценарии не становятся их primary за счёт большого объёма.
- Не смешивать X2 с X2 Ultra/A2/A3, BellaBot с Pro, конфигурации Unitree, разные шахматные продукты SenseRobot.
- Bumi содержит посторонний музыкальный/иностранный спрос; «робот художник» — игрушки/конструкторы; «робот бармен» — кино; «шашки» — дымовые шашки. Эти строки исключаются из смыслов карточек.
- Низкий спрос по имени не повод выдумывать частоты или превращать страницу модели в универсальную подборку.
- Следующий пилот: Робошашки + SenseRobot, затем остальные модели без повторения общего Wordstat.
