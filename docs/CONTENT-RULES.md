# Правила контента

- Alt описывает только видимое и не содержит цену или набор SEO-ключей.
- Самостоятельная аренда робота не предлагается; услуга оказывается с сопровождающим специалистом.
- Цена услуги не смешивается с ценой покупки робота.
- Рядом с ценой выводится «Не является публичной офертой».
- Операционные характеристики подтверждает менеджер при бронировании.
- `draft` и `review` доступны только в preview; `published` — в production и sitemap; `archived` не публикуется.
- Количество facts, scenarios и FAQ переменное в пределах schema, а не фиксированное.
