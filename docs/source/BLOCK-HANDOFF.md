## 0. Как пользоваться этим документом

1. Этот документ содержит **все неочевидные решения дизайн-итераций**, которых нет в ТЗ и в `Правки.xlsx`.
2. При расхождении `Правки.xlsx` и раздела 5 настоящего файла — **приоритет у раздела 5** (решения итераций, утверждённые владельцем визуально). Расхождения помечены ⚠️ и продублированы в разделе 6 для подтверждения владельцем.
3. Визуальная проверка — только по эталонным сборкам (раздел 2).
4. Порядок работ — раздел 13 (соответствует этапам 0–8 ТЗ).

## 1. Контекст проекта

- **Сайт**: аренда роботов для мероприятий (Москва + вся Россия), собственный парк «КИБЕР ПОРТАЛ».
- **Стек**: Astro (SSG) + TypeScript + YAML + Zod + GitHub + Coolify; AI-агент Hermes — только через PR.
- **Шрифты**: **Gilroy** — заголовки и кнопки; **Montserrat** — все тексты. Fallback Arial без скачка layout. Лицензия/файлы Gilroy — открытый вопрос (блокер типографики и production, ТЗ §25).
- **Состояние на момент передачи**: пройдены дизайн-ревью desktop и mobile по блокам 01–34; собраны эталонные страницы; подготовлен скелет дизайн-системы (раздел 12).

## 8. Бизнес-правила (ТЗ §11.2, проверять схемами и content-тестами)

- Самостоятельная аренда не предлагается; сопровождение специалистом обязательно.
- Цена услуги = calculated (факторы: длительность, программа, логистика); рядом пометка «не является публичной офертой».
- Цена покупки и цена аренды — разные поля, не смешивать.
- Карточка робота — тупик: ссылки только в каталог / другие карточки / главную.
- Статусы публикаций: draft/review/published/archived; draft не попадает в production.

## 14. Definition of Done правки (напоминание из ТЗ §24)
