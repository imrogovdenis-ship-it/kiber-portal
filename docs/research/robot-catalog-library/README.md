# Исследовательская база каталога КИБЕР ПОРТАЛ

Цель: один сбор источников для всего каталога и дальнейшая работа по одной карточке без регулярного подключения к ПК владельца.

Wordstat переиспользуется. Проверенные исследования первых моделей не собираются заново; проходят аудит полноты и связываются с реестром. Для остальных моделей сохраняются выдача, конкретные предложения аренды, источники производителя, извлечённые факты, противоречия и решения для блоков. Один успешный HTTP-запрос или набор ссылок не делает модель готовой к написанию.

manifest.json — состояние по каждой модели. До проверки источников readyForWriting=false. Полные промежуточные захваты хранятся в закрытой рабочей области агента; в Git входят структурированные факты, оригинальные выводы и короткие подтверждающие выдержки с URL/датами. Cookies, пароли, токены и browser storage не сохраняются.

Данные о конкретном экземпляре, составе услуги и доступном репертуаре, которые нельзя подтвердить открытыми источниками, выносятся в общий список вопросов владельцу. Никаких изменений страниц, media runtime, API, DNS, CRM или production.

## Контрольная точка

Сбор не завершён. Текущее состояние — collection-status.json; непрочитанные полностью источники — missing-sources.json. 36 поисковых запросов сохранены, 45 источников имеют читаемые захваты, но ещё требуют содержательной проверки; 18 источников требуют восстановления/замены. Некоторые названия дали нерелевантную выдачу: Клипмейкер (профессия), UV-BOX (УФ-приборы), София (разные платформы). Это не доказательства для соответствующих карточек. Следующий проход — уточняющие запросы и недостающие страницы, без повторения готовых захватов.

Эта контрольная точка не объявляет readyForWriting=true и не разрешает публикацию или изменение карточек.
