# Общие правила оформления подборок

Утверждены владельцем на примере «Роботы-гуманоиды». Основа — CompilationTemplate и shared-блоки утверждённой главной PR8. Стили самостоятельно не переизобретать.

- Hero: на широком экране заголовок, описание, CTA слева; заметное изображение справа. Кадрирование 4:3 по центру допустимо после проверки композиции; narrow-экраны — полный 16:9. Исходник не обрезать. Подборке без подходящего изображения не назначать случайное.
- После вводной части/галереи — содержательный блок, объясняющий класс роботов и пользу аренды, без повторения intro. При наличии — общее горизонтальное видео 16:9 рядом по смыслу.
- Вертикальные карточки могут быть видео по моделям, а не обязательно фотосценариями: использовать реальные ролики 9:16 с точными подписями.
- Kinescope: нативная кнопка Play сразу, lazy iframe, без дополнительного шага «Смотреть видео», без внешней ссылки под роликом; без автозапуска со звуком. Токен только на сервере, реестр видео отдельно. Privacy/rights production review обязателен перед публикацией.
- Цитаты: сохранить вводную и завершающую, если они предусмотрены; вводная часть/шутка жирным, менеджерский handoff после отступа обычным шрифтом; уникальные IDs.
- Каталог → Блог Кибер Гоши → Подборки: существующие shared-компоненты. Единый padding clamp(2.1rem,3.8vw,3.4rem), mobile 2.75rem; без дополнительных внешних margin. В humanoid launch — 7 моделей, 6 утверждённых статей; это наполнение конкретной подборки, не обязательное количество для всех будущих.
- Не менять утверждённые тексты/медиа/стили вне явно названного feedback scope.
- Неготовые подборки: некликабельная карточка «Скоро», без href/фиктивной страницы; не заменять ссылкой на главную. В sitemap только готовые индексируемые страницы.

Утверждение подборки не означает merge/production/DNS/analytics/live routing approval.
